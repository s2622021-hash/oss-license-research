This page summarizes common open-source licenses.

MIT License

Type: Permissive.

Allows: use, copy, modify, merge, publish, distribute, sublicense and sell the software, including in commercial projects.

Requires: keep the original copyright notice and license text in copies of the software.

Limits: the software is provided "as is" with no warranty and the authors are not liable.

Apache License 2.0

Type: Permissive.

Allows: use, modify and distribute the software, including commercially.

Requires: keep copyright and license notices, and state any changes you made.

Extra: includes an explicit patent grant from contributors.

GNU General Public License v3 (GPL v3)

Type: Copyleft (strong).

Allows: use, study, modify and distribute the software, including commercially.

Requires: if you distribute the software or a modified version, you must release it under the same GPL v3 license and make the source code available. You must also keep copyright and license notices.

Extra: includes a patent grant, and stops people from adding extra restrictions to the code.
